# Деплой на Vercel

## Подключение репозитория

1. Откройте Vercel Dashboard.
2. Выберите создание нового проекта.
3. Подключите GitHub-репозиторий с прототипом.
4. Выберите ветку с реализацией.

## Настройки сборки

- Шаблон фреймворка: `Next.js`.
- Команда установки: `npm install`.
- Команда сборки: `npm run build`.
- Выходная директория: оставить пустой или стандартной для Next.js.

## Переменные окружения

Добавьте переменные:

```text
OPENROUTER_API_KEY
OPENROUTER_MODEL
OPENROUTER_BASE_URL
NEXT_PUBLIC_APP_NAME
```

Минимально обязательна только `OPENROUTER_API_KEY` для ИИ-модуля. Если ключ не задан, `/api/llm/analyze` вернет предупреждение, а остальные разделы приложения продолжат работать.

## Данные

В репозитории должен быть файл:

```text
src/data/generated/normalized-records.json
```

Папку `data/source/` нельзя деплоить и коммитить, потому что там лежат сырые выгрузки. Перед деплоем локально выполните:

```bash
npm run prepare:data
```

## Проверка деплоя

После публикации проверьте:

- `/source-data` открывает таблицу подготовленных записей;
- `/dashboard` показывает показатели и графики;
- `/project-evaluation` показывает итоговую оценку;
- `/forecasting` показывает три сценария прогноза;
- `/llm-analyst` либо получает ответ OpenRouter, либо показывает предупреждение об отсутствии ключа.

## Серверный маршрут

Маршрут:

```text
POST /api/llm/analyze
```

работает как серверная функция Vercel. Ключ OpenRouter читается только на сервере и не передается в браузер.
